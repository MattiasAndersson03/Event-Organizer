# 🗓️ Event Organizer

A C# (Windows Forms) project for creating and managing events and participants.

---

## 🧭 Features

- Create, edit, and delete events  
- Add participants and link them to events  
- Manage address and country information  
- Display lists of events and participants  
- Basic validation and error handling  

---

## 📁 Project Structure

| File | Description |
|------|-------------|
| `Program.cs` | Entry point of the application |
| `Form1.cs` / `Form1.Designer.cs` | Main form and UI components |
| `EventManager.cs` | Logic for managing events |
| `ParticipantManager.cs` | Logic for managing participants |
| `Participant.cs`, `Address.cs`, `Countries.cs` | Domain classes |
| `App.config` | Configuration file |
